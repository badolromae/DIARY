# EnJJoy V2.0 — 폐쇄형 개인 다이어리 (WeJJoy UI/위젯 적용)

이 버전은 **WeJJoy의 디자인·움직임·위젯 스타일**을 EnJJoy에 이식한 버전입니다.
공유 기능은 모두 제거했고, **모든 기록은 이 기기 안에만 저장되는 폐쇄형 다이어리**로 유지됩니다.

## 반영 내용
- WeJJoy 메인 화면 구조 적용
  - 달력 영역 접기/펼치기 애니메이션
  - 아래로 당기면 달력 다시 펼쳐지는 동작
  - 선택 날짜 옆 음력 표시
- WeJJoy 위젯 스타일 적용
- 테마 8종 적용
  - 딥그린, 스카이블루, 연핑크, 블랙+그레이, 레드+주황, 군청, 연그린, 노랑
- 사진 첨부 시 EXIF 회전 보정 적용
- 설정 버전 문구를 **EnJJoy V2.0** 으로 변경
- 공유/Firebase 관련 화면과 동작 제거

## 주의
이 ZIP은 **전체 프로젝트가 아니라 바꿀 파일만 담은 패치용 ZIP**입니다.
기존 EnJJoy 저장소 루트(`DIARY-main`)에 덮어써서 사용하세요.
