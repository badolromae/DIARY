# 나만의 다이어리 (MyDiary) — 안드로이드 앱

누구에게도 공유하지 않는, **오직 내 삼성 갤럭시 폰에만 저장되는** 개인 다이어리 앱입니다.

## 주요 기능
- **일기 · 일정 작성**: **시작 날짜·시간 ~ 종료 날짜·시간(여러 날 가능)**, 제목·본문,
  기분 이모지, **중요도(1~100%)**, 태그, 사진 첨부
- **한국 공휴일 · 기념일**: 공휴일(대체공휴일 자동 계산)은 **일요일과 같은 빨간색**,
  법정기념일·세시풍속·생활기념일 표시
- **음력 표시**: 달력 날짜 아래에 작은 글씨로 `음7.14` (1900~2050년, KASI 기준)
- **홈 화면 위젯 3종** (크기 조절로 화면 가득 채우기 가능)
  - 월 달력: 날짜를 누르면 그 날로 바로 이동, 기록 있는 날은 표시, 음력·공휴일 함께 표시
  - 주 달력: 요일별 일정 목록
  - 일 달력: 시간순(아젠다) 목록
- **알림**: 매일 정해진 시간 알림 + 개별 일정 알림 / **소리·진동·소리+진동·무음**을 설정에서 전환
- **보안 잠금**: PIN + 지문/얼굴 인식
- **딥그린 + 블랙 포인트 디자인**, 다크 모드 자동 지원
- **완전 오프라인**: 인터넷 권한 없음. 데이터·사진은 폰 내부에만 저장됩니다.

> 업데이트 내용과 깃허브 반영 방법은 **[업데이트-안내.md](업데이트-안내.md)** 를 참고하세요.

## ⚠️ 먼저 읽어주세요
안드로이드 앱은 구글의 빌드 도구로 컴파일해야 설치 파일(APK)이 만들어집니다. 이 프로젝트는 그 과정을
**깃허브(GitHub)가 무료로, 클라우드에서 자동으로** 해주도록 설정되어 있습니다.
따라서 **컴퓨터에 아무것도 설치하지 않아도** APK를 받을 수 있습니다. (아래 “방법 A”)

준비물: **깃허브 계정 하나** (무료). 없으면 https://github.com/signup 에서 가입하세요.

## 방법 A — 깃허브 자동 빌드로 APK 만들기 (권장, 안드로이드 스튜디오 불필요)

### 1) 새 저장소(repository) 만들기
1. https://github.com/new 접속
2. Repository name: 예) `my-diary`
3. **Private**(비공개) 선택 (나만 보기)
4. 아래쪽 초록색 **Create repository** 클릭

### 2) 프로젝트 파일 업로드
1. 방금 만든 저장소 화면에서 **uploading an existing file** 링크 클릭
   (또는 `Add file ▸ Upload files`)
2. 받은 압축파일(`MyDiary-project.zip`)을 컴퓨터에서 **압축 해제**
3. 압축을 푼 폴더 안의 **모든 파일과 폴더를** (숨김 폴더 `.github` 포함) 업로드 창으로 **드래그**
   - 폴더째 드래그하면 하위 파일까지 함께 올라갑니다.
   - `app`, `gradle`, `.github`, `build.gradle`, `settings.gradle`, `gradlew`, `gradlew.bat`, `gradle.properties` 가 모두 보여야 합니다.
4. 아래 **Commit changes** 클릭

> 💡 `.github` 폴더가 안 보이면, 압축 해제한 폴더에서 숨김 파일 보기를 켜고 그 폴더도 함께 드래그하세요. 이 폴더가 있어야 자동 빌드가 동작합니다.

### 3) 자동 빌드 기다리기
1. 파일이 올라가면 자동으로 빌드가 시작됩니다.
2. 저장소 상단의 **Actions** 탭 클릭
3. `Build APK` 실행 항목을 클릭 → 초록색 체크(✓)가 뜰 때까지 기다립니다. (보통 3~6분)
   - 처음엔 노란 점(진행 중)입니다. 완료되면 초록 체크로 바뀝니다.

### 4) APK 내려받기
1. 완료된 실행 화면 맨 아래 **Artifacts** 항목의 **`MyDiary-APK`** 클릭 → zip 파일이 다운로드됩니다.
2. zip 안에 **`app-debug.apk`** 가 들어 있습니다. 압축을 풀어 이 APK를 폰으로 옮기세요.
   (카카오톡 “나에게 보내기”, 구글 드라이브, USB 케이블, 이메일 등 무엇이든 가능)

> 다시 빌드하려면: 저장소에서 파일을 수정해 커밋하거나, **Actions ▸ Build APK ▸ Run workflow** 를 눌러 수동 실행하면 됩니다.

## 방법 B — 안드로이드 스튜디오로 직접 빌드 (선택)
개발 도구가 있는 경우:
1. 압축 해제한 폴더를 Android Studio에서 **Open**
2. Gradle 동기화가 끝나면 상단 메뉴 **Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)**
3. 완료 알림의 **locate** 클릭 → `app/build/outputs/apk/debug/app-debug.apk`
4. 또는 폰을 USB로 연결하고 ▶(Run) 버튼으로 바로 설치

---

## 폰에 설치하기 (삼성 갤럭시)
1. 옮긴 `app-debug.apk` 파일을 **내 파일** 앱에서 탭
2. “이 출처의 앱 설치”가 막혀 있으면, 안내에 따라 **이 출처 허용**을 켠 뒤 다시 설치
   (설정 ▸ 보안 및 개인 정보 보호 ▸ 알 수 없는 앱 설치)
3. **설치** → 완료

> 이 APK는 개인용(디버그) 서명입니다. 개인 사용/사이드로드에는 문제없지만, 플레이스토어 등록용은 아닙니다.

---

## 처음 실행 시 권한 허용
- **알림 권한**: 첫 실행 시 물어봅니다. 알림을 쓰려면 **허용**.
- **정확한 알람(알람 및 리마인더)**: 정해진 시간에 정확히 울리게 하려면, 설정 화면에서 매일 알림을 켤 때 안내가 뜹니다. **설정 열기 ▸ 허용**.
- **사진**: 사진 첨부 시 갤러리 선택 화면이 뜹니다(사진 접근 권한 없이 동작하는 안전한 방식).

---

## 홈 화면에 위젯 추가하기 (화면 가득 채우기)
1. 홈 화면의 빈 곳을 **길게 누르기** → **위젯**
2. 목록에서 **다이어리** 를 찾습니다.
3. **월 달력 / 주 달력 / 일 달력** 중 원하는 위젯을 홈 화면으로 드래그
4. 위젯을 한 번 더 **길게 눌러** 나타나는 파란 테두리의 **점(핸들)** 을 바깥으로 끌어 **화면 가득** 크기로 조절
5. 위젯 안의 화살표(◀ ▶)로 이전/다음 달·주·일 이동, 가운데 아이콘으로 오늘로 이동, 일 위젯의 **+** 로 바로 추가

## 사용법 요약
- **＋ 버튼**: 선택한 날짜에 새 일기 작성
- **달력의 날짜 탭**: 그 날의 기록 보기 / 점이 있는 날 = 기록 있는 날
- **중요도 슬라이더**: 1~100%로 조절, 목록·위젯에 막대로 표시
- **알림**: 편집 화면에서 “이 일기에 알림 설정”을 켜고 시간 지정 (개별 알림)
- **설정(오른쪽 위 톱니)**: 매일 알림 시간, 알림 방식(소리/진동/소리+진동/무음), 앱 잠금(PIN·생체인식)
- **검색(오른쪽 위 돋보기)**: 제목·내용·태그로 검색

## 개인정보 & 백업
- 모든 데이터와 사진은 **이 기기 안에만** 저장됩니다. 서버 전송·공유가 전혀 없습니다.
- 자동 클라우드 백업이 **꺼져 있습니다**(`allowBackup=false`). 그만큼 안전하지만, **앱을 삭제하면 기록도 사라집니다.** 기기 변경 시 주의하세요.

## 문제 해결
- **Actions에서 빨간 X(빌드 실패)**: 실패한 단계를 클릭해 로그를 확인하세요. 대부분 파일 일부가 누락되어 업로드된 경우입니다. `.github` 폴더와 `gradlew` 파일이 포함됐는지 확인 후 다시 올려보세요.
- **위젯 목록에 안 보임**: 앱을 한 번 실행한 뒤 몇 분 기다렸다가 다시 시도하세요. (기기가 위젯 목록을 갱신하는 데 시간이 걸릴 수 있습니다.)
- **알림이 정시에 안 옴**: 설정에서 “알람 및 리마인더” 권한을 허용했는지, 배터리 절약에서 이 앱이 “제한 없음”인지 확인하세요. (삼성: 설정 ▸ 배터리 ▸ 백그라운드 사용 제한 해제)
- **알림 소리/진동이 설정과 다름**: 안드로이드는 알림 채널별로 소리·진동을 관리합니다. 앱 설정에서 방식을 바꾸면 다음 알림부터 해당 방식으로 울립니다.
